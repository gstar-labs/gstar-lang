# Security and soundness

A **soundness bug** is any case where the checker accepts a program that does
not meet its written contracts. It is the most serious kind of bug
in g-star.

## Reporting

Report soundness bugs and other vulnerabilities privately, through
**GitHub private vulnerability reporting** on this repository ("Report a
vulnerability" under the Security tab).

## How fixes land

Fixes are made as ordinary pull requests, through the same gate and merge queue
as every other change. A published GitHub security advisory accompanies the
release that contains the fix, and lists the affected rules and migration notes.
